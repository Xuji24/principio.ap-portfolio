## ✨ About

This repository powers my personal portfolio — a single-page site that introduces who I am, showcases the projects I've shipped, and provides a way to get in touch. It's built with the Next.js App Router, animated with Framer Motion, and themed with a custom light/dark switch.

## 🧩 Features

- 🎬 **Animated hero & sections** — scroll-based reveals powered by Framer Motion and Lenis smooth scrolling
- 🌗 **Light / dark theme** — persisted theme switch via a custom `ThemeContext`
- 🌌 **Interactive background** — Vanta.js / Three.js canvas effects with particle accents
- 🧵 **Tech stack showcase** — animated logo loop and icon cloud of tools & languages
- 💼 **Projects grid** — featured and secondary project cards with live demo & GitHub links
- 📜 **Journey & certifications** — timeline of experience and credentials
- 🤖 **Chatbot header** — assistant entry point on the top nav
- 📬 **Contact form** — email delivery via Nodemailer, backed by Supabase for data storage
- 📱 **Fully responsive** — mobile-first layout across every section

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/Xuji24/principio.ap-portfolio.git
cd principio.ap-portfolio
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

Other available scripts:

```bash
npm run build   # production build
npm run start   # start production server
npm run lint    # run ESLint
```
